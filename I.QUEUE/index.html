BUILDING BLOCKS
Skill Blocks
Define capabilities as typed Python functions with @skill decorator. Not text descriptions — real code.
Memory Rod
The vertical rod spans all pipeline layers. Flash → session → deep. One module, three lifespans.
Rule Engine
Constraints as executable @rule functions. Structure prevents chaos — no runtime surprises.
Alignment Formula
Replace vague guidelines with weighted, computable scores. score = 0.4×safety + 0.4×helpfulness.
Phase Pipeline
Explicit ordered stages. Each phase must complete before the next unlocks — natural gate logic.
Cartridge Presets
Assistant, Project, Memory, Audit — pre-built recipes. Pick one, drop it in, run.
