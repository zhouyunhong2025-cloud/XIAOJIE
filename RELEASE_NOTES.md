# Release Notes - v0.1.0: "Free Your AI Agent" 🚀

## 📖 The Story Behind I.QUEUE

Ever spent hours configuring AI agents? Memory configs, skill definitions, preference parameters, safety rules... It's chaos. 

**We asked a simple question:** What if your AI agent could configure itself?

Today, we're releasing **I.QUEUE v0.1.0** — the moment when everything changed.

---

## ✨ What's New

### 🎯 One-Sentence AI Agent Design
Describe what you need in one sentence. I.QUEUE auto-designs:
- **Memory** — How your agent remembers
- **Skills** — What it can do  
- **Preferences** — How it behaves
- **Rules** — What it won't break

### 🚀 Instant Deployment
- 10 seconds from idea to working agent
- No configuration files to write
- No manual parameter tuning
- Done.

### 🎮 Three Ways to Use
1. **Web UI** — Beautiful visual interface (FastAPI)
2. **Desktop Monitor** — Real-time processing visualization (PyQt6)
3. **CLI** — Command-line power users

### 📊 6-Step Automatic Design Pipeline
1. **Requirement Analysis** — Parse your one-sentence need
2. **Skill Recommendation** — Suggest the perfect capabilities
3. **Rule Setup** — Define safety boundaries
4. **Memory Design** — Build persistent knowledge layer
5. **Alignment Scoring** — Verify preference alignment
6. **Plan Generation** — Output executable YAML config

### 🌍 100% English Localization
- Full internationalization across codebase
- Works globally from day one
- Documentation in English, Chinese, and ready for more

## 🏃 Quick Start

```bash
# 1. Install (1 minute)
pip install -r requirements.txt

# 2. Run (1 minute)
python run.py

# 3. Choose your interface
#    → Full Mode (Web + Desktop)
#    → Web Only
#    → CLI Only

# 4. Describe your agent
# "Create a daily news curation agent for tech news"

# ✅ Done in 10 seconds!
```
